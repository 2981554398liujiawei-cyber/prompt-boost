# ChatGPT 网页手工冒烟检查清单（Stage 8）

> 目的：在真实 `chatgpt.com` 页面人工验证扩展闭环，覆盖 jsdom 单测覆盖不到的真实 DOM、React 事件与网络链路。
> 前置：本地服务已启动（`scripts\start-prompt-boost.cmd` 或 `pnpm agent:start`），Options 页已配置 Provider 并「测试连接」成功，扩展已加载（`apps/extension/dist`）。
> 每项完成后勾选。失败项记录到「问题记录」，不应通过整体验收。

---

## A. 加载与按钮注入

- [ ] 打开 `https://chatgpt.com`（或 `chat.openai.com`），等待输入框出现。
- [ ] 输入框旁出现 `✨ Boost` 按钮。
- [ ] 刷新页面 / 切换会话后按钮重新出现（SPA 重挂载）。
- [ ] 同一页面不出现重复按钮（仅一个 `✨ Boost`）。

## B. 基础增强闭环

- [ ] 输入任意原始需求（如「帮我写一个产品推广方案」）。
- [ ] 点击 `✨ Boost` → 短暂「分析中…」→ 写回增强后的 Prompt。
- [ ] 写回内容为「改写后的指令」而非直接回答任务（不含「好的，我来…」）。
- [ ] 增强后出现「已增强 ✓ [撤销]」；点击撤销恢复原文。
- [ ] 增强过程网络面板（F12 → Network → Fetch/XHR）恰好 1 次 `/v1/enhance` 请求（正常无追问路径）。

## C. 二级菜单

- [ ] 点击 `✨ Boost ▾` 的 ▾ 打开菜单。
- [ ] 菜单包含五组：增强模式 / 任务类型 / 自动追问 / Prompt 评分 / API 设置。
- [ ] 点击菜单外区域 / 按 Esc → 菜单关闭。
- [ ] Tab / Enter / Space 可操作菜单（键盘导航 + aria 选中态）。
- [ ] 菜单跟随页面深色 / 浅色主题。
- [ ] 切换「增强模式」→ 快速/深度/专家 → 刷新页面后保持（已持久化）。
- [ ] 任务类型显示「自动 · 商业」等已检测类型；手动选择后显示所选值。
- [ ] 点击「API 设置」→ 打开 Options 页。

## D. Prompt 评分

- [ ] 菜单「Prompt 评分」→ 显示八维评分与总分。
- [ ] 来源显示「AI 分析」（或「本地估算」），不含任何内部 code / `heuristic_fallback` 字样。
- [ ] 增强后编辑输入框 → 评分显示「已过期」（不自动重新调用模型，网络面板无新请求）。

## E. 自动追问（Clarification）

- [ ] 输入一个信息不足的 Prompt → 增强 → 弹出追问面板（≤3 个问题）。
- [ ] 面板含三按钮：取消 / 使用默认假设 / 回答并增强。
- [ ] 点「回答并增强」：填写部分答案 → 网络面板共 2 次 `/v1/enhance` 请求（首轮 + 带答案二轮）。
- [ ] 点「使用默认假设」：直接写回首轮增强结果，网络面板仅 1 次请求。
- [ ] 点「取消」：输入框不变，回到 idle。
- [ ] 「自动追问」切到 `off`：即使模型产出问题也不出现追问面板（1 次请求）。

## F. 冲突保护与错误 UX

- [ ] 输入 → 点 Boost → 请求进行中（「分析中…」）时修改输入框 → 返回后出现冲突确认面板。
- [ ] 冲突面板三按钮：取消（保留当前输入）/ 复制增强结果 / 覆盖当前内容。
- [ ] 未配置 Provider 时点 Boost → 提示「还没有配置可用的 AI Provider…」（不含内部错误码 / 堆栈）。
- [ ] 停止本地服务后点 Boost → 提示「无法连接本地服务…127.0.0.1:8787」。

## G. 安全抽查

- [ ] Options 页不显示完整 API Key（仅「已配置」），重新打开仍如此。
- [ ] 网络面板的请求中不出现 API Key 明文（仅出现在 `Authorization: Bearer` 头，且该头只发往你配置的 Base URL）。
- [ ] 本地服务日志无 Key 明文、无完整令牌（启动日志为 `pb_****xxxx` 脱敏形式）。

## H. 令牌与重启

- [ ] `pnpm agent:token:show` 显示完整令牌（主动命令）；`pnpm agent:token:rotate` 后旧令牌失效，Options 填入新令牌恢复连接。
